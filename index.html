02 Proyectos

SentinelScan

Escáner de vulnerabilidades web que analiza cabeceras, TLS, formularios y endpoints expuestos, generando reportes priorizados por riesgo.

  • Python
  • OWASP
  • CLI

AuthGuard

Servicio de autenticación con MFA (TOTP y WebAuthn), gestión de sesiones y rotación automática de tokens para aplicaciones empresariales.

  • Go
  • JWT
  • WebAuthn

LogHawk

Plataforma de centralización y correlación de logs con reglas de detección personalizables y alertas en tiempo real vía webhooks.

  • Elasticsearch
  • Node.js
  • Docker

VulnTrack

Gestor de vulnerabilidades que integra resultados de distintos escáneres y asigna severidad, responsables y plazos de remediación.

  • FastAPI
  • PostgreSQL
  • React

CryptoVault

Bóveda de secretos cifrada de extremo a extremo con auditoría de accesos y control de versiones para credenciales de producción.

  • Rust
  • AES-256
  • Vault API

APIShield

Gateway con rate limiting, validación de esquemas y WAF ligero para proteger APIs REST frente a abuso y ataques de inyección.

  • Go
  • WAF
  • Kubernetes
